# MSHI Leadership Practicum AI Dashboard  
### MSM Community Care Network Operational Analysis

---

## Practicum Context

This project analyzes a de-identified operational dataset from MSM Community Care Network (MSM-CCN), a hybrid healthcare model affiliated with an academic medical institution. The network includes Primary Care, Behavioral Health, a Diabetes Clinic, and Telehealth services.

Leadership has requested data-driven insights to identify workflow bottlenecks, communication challenges, and opportunities to improve patient engagement and operational efficiency.

---

## Leadership Question

What operational patterns in appointment attendance, wait times, and communication channels suggest workflow bottlenecks or opportunities for leadership intervention?

---

## Data Description

The dataset includes three months of de-identified operational records. Each row represents a single client interaction and includes variables such as:

- Department/service line  
- Appointment status (attended or no-show)  
- Wait time  
- Service duration  
- Communication channel (portal, phone, in-person, email, outreach)  
- Client satisfaction indicators  

The dataset contains between 50–300 records and is used for academic analysis purposes only.
